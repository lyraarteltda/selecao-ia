Política de Privacidade

Última atualização: 12/10/2026

Esta Política de Privacidade descreve como a ferramenta Seleção IA, oferecida pela comunidade Maestros da IA, coleta, utiliza e protege os dados pessoais dos seus usuários, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Dados Coletados

Coletamos apenas os dados estritamente necessários para o funcionamento da ferramenta:

  • E-mail: para verificação de acesso à comunidade.
  • Telefone (WhatsApp): para verificação de acesso à comunidade.

Sua chave de API da OpenRouter é armazenada apenas no seu navegador (localStorage) e nunca é transmitida para nossos servidores — ela vai direto da sua máquina para a OpenRouter. As vagas, rubricas, currículos e avaliações também ficam apenas no seu navegador: os arquivos são lidos localmente e o texto de cada currículo é enviado somente ao provedor de IA da sua chave, no momento da avaliação. Nós não recebemos nem armazenamos currículos.

1.1 Dados de candidatos

Ao usar a ferramenta para triar currículos, você é o controlador dos dados pessoais dos candidatos (LGPD, art. 5º, VI) e deve tratá-los apenas para o processo seletivo, informar os candidatos e apagá-los quando o processo terminar (use “Apagar” em Vagas salvas). A ferramenta oferece o modo cego e instrui a IA a não considerar características protegidas, mas a decisão de contratação é sempre humana e de sua responsabilidade.

2. Finalidade do Tratamento

  • Verificação de acesso: confirmar que o usuário é membro ativo da comunidade.
  • Suporte e melhoria: responder a feedback enviado voluntariamente pela ferramenta.

3. Base Legal

O tratamento de dados é realizado com base no legítimo interesse (Art. 7º, IX da LGPD) para verificação de acesso e na execução de contrato (Art. 7º, V) referente à assinatura da comunidade Maestros da IA.

4. Compartilhamento de Dados

Seus dados não são vendidos ou compartilhados com terceiros para fins comerciais. Utilizamos os seguintes serviços técnicos (operadores):

  • Supabase: banco de dados para verificação de membros, acessado exclusivamente pelo nosso servidor (o navegador nunca acessa o banco).
  • n8n: intermediação segura entre a ferramenta e o banco de dados.
  • Netlify: hospedagem da aplicação web.
  • OpenRouter: provedor de IA acionado diretamente pelo seu navegador com a sua chave — nós não intermediamos essa chamada.

5. Período de Retenção

  • Dados de verificação: mantidos enquanto o usuário for membro ativo da comunidade.
  • Dados no navegador (chave, vagas, currículos e avaliações): permanecem até você limpá-los pela ferramenta ou pelo navegador.

6. Seus Direitos (LGPD)

Você tem direito a:

  • Confirmação da existência de tratamento de dados;
  • Acesso aos seus dados pessoais;
  • Correção de dados incompletos ou desatualizados;
  • Eliminação dos dados pessoais (veja o link abaixo);
  • Informação sobre compartilhamento de dados;
  • Revogação do consentimento.

7. Segurança

  • Comunicação criptografada (HTTPS/TLS);
  • Row-Level Security (RLS) no banco de dados;
  • Limitação de taxa de requisições;
  • Sua chave de API nunca é armazenada no servidor.
